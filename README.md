# Bar Nightcap - 放置バー

バーのカウンターに座って、好きなカクテルやお酒を頼んだり、葉巻をくゆらせたりしながら
のんびり時間を過ごすデスクトップ放置型ゲームです。ブラウザで `index.html` を開くだけで遊べます
（ビルド不要、依存ライブラリなし）。

## 遊び方

- 時間経過でゴールドが自動的に貯まります（放置ゲーム要素）。
- 貯まったゴールドでドリンクや葉巻を注文できます。
- ドリンクは「満足度（レベルアップに必要な経験値）」と「ほろ酔い」を、
  葉巻は「満足度」と「リラックス」を上げます。
- ほろ酔い・リラックスが高いほどゴールドの獲得レートが上がりますが、
  ほろ酔いが100%になると「泥酔」状態になり、一定時間ペナルティを受けます。
- レベルが上がると新しいドリンク・葉巻がアンロックされます。
- 実績を解除するとボーナスゴールドがもらえます。
- ページを閉じても、次に開いたときにオフライン中に貯まったゴールドを受け取れます。
- 進行状況はブラウザの `localStorage` に自動保存されます。

## ファイル構成

- `index.html` - 画面構造
- `style.css` - 見た目（バーの雰囲気、ネオンサイン、グラス・葉巻の演出など）
- `script.js` - ゲームロジック（状態管理、放置計算、実績、セーブ/ロード）
